# Hermes WebUI 原版后端 API 接口文档

来源：`hermes-webui/api/routes.py`、`api/kanban_bridge.py`、`api/upload.py`。

## 约定

- 基础路径：所有接口均以 `/api` 或 `/health` 为入口。
- JSON 接口默认使用 `application/json`；上传接口使用 `multipart/form-data`；SSE 接口返回 `text/event-stream`。
- 通用错误通常为 `{ "error": string }`；`bad(handler, msg, status)` 默认状态码为 400。
- 原版 Session 主键字段为 `session_id`，不是 `id`。
- 字段类型由源代码的 `body.get(...)`、`parse_qs(...)`、`isinstance(...)`、响应字典与校验分支静态抽取；复杂对象在文档中以 `object`/领域对象描述。
